# Overview

This is my GitHub pages website built using Jekyll on the al-folio template. I've changed some of the formatting and collections to better fit this site, but the template has helped a great deal to get started. This is a place for me to host my research and side projects as well as to host some blog tutorials that I've started writing for more niche coding concepts (currently starting with MPI and CUDA) that are applicable to machine learning systems.

# Layout

The layout of the website is fairly self-explanatory:

- About - small biography section with links to my social accounts (email, GitHub, and LinkedIn)
- Blog - A place to talk about some interesting aspects of computer science and related fields. My style of learning is to keep asking questions and dive deep into things, and that's the style I've primarily been employing here.
- Research - Displays "research" collections in a tile-grid. This tab contains longer papers I've written (like my thesis in computer vision) as well as smaller, self-contained research investigations (more like a Kaggle data set)
- Propjects - Displays "project" collections in a tile-grid. This tab contains websites and other self-contained projects I've worked on. These pages are mainly meant to give overviews on them, but I might also write more about them in a blog if something is opaqure or particularly interesting to dissect.
- Repositories - links to my public GitHub repositories
- Search functionality throughout the site
